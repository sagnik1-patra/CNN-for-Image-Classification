CNN FOR CIFAR-10 IMAGE CLASSIFICATION
===========================================================================

1. DATASET
---------------------------------------------------------------------------
CIFAR-10 contains 60,000 RGB images of size 32x32 divided into 10 balanced classes. The training set contains 50,000 images and the test set contains 10,000 images. A validation subset is created from the original training set.

2. PREPROCESSING
---------------------------------------------------------------------------
Pixel values are normalized to the range 0-1. Labels are converted to one-hot vectors. Training images are augmented with horizontal flips, rotations, shape-preserving translations, and contrast changes.

3. ARCHITECTURES
---------------------------------------------------------------------------
The baseline CNN uses two convolution and pooling stages followed by a dense layer and dropout. The advanced model uses residual blocks, batch normalization, dropout, and L2 regularization. MobileNetV2 is used for transfer learning.

7. OBSERVATIONS
---------------------------------------------------------------------------
Data augmentation improves generalization by adding realistic variation. Batch normalization stabilizes activation distributions and often speeds convergence. Dropout reduces overfitting by randomly disabling activations during training. Residual connections improve gradient flow and make deeper networks easier to train. Learning-rate reduction helps the optimizer make smaller updates near a minimum. Transfer learning reuses features learned from ImageNet. Ensembling can improve accuracy when models make different errors.

8. POSSIBLE IMPROVEMENTS
---------------------------------------------------------------------------
1. Fine-tune the last MobileNetV2 layers.
2. Use MixUp or CutMix augmentation.
3. Apply label smoothing.
4. Use cosine learning-rate scheduling.
5. Train longer on a GPU.
6. Tune dropout and L2 strength.
7. Use weighted ensemble averaging.
